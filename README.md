# 🕵️ Mafia Game

A multiplayer browser-based Mafia game built with **HTML, CSS, JavaScript, Node.js, and Socket.IO**.

## 🎮 Features

* 👥 Multiplayer rooms
* 🕵️ Mafia vs Villagers
* 🔎 Investigation system
* 🌙 Night actions
* ☀️ Daytime discussions and voting
* 🎭 Hidden roles
* ⚡ Real-time multiplayer using Socket.IO

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Node.js
* Express
* Socket.IO

## 🚀 Run Locally

### 1. Install dependencies

```bash
npm install
```

### 2. Start the server

```bash
node server.js
```

### 3. Open the game

Go to:

```text
http://localhost:3000
```

## 🌐 Online Version

The game can be deployed to a Node.js-compatible hosting service so players can join using a public URL without the host running the server locally.
